
# Deployment Documentation

## Deployment Options

* **Developer Deployment**: Deploy personal stacks using the [dev-deploy utility](https://github.com/govuk-one-login/ipv-core-common-infra/tree/main/utils/dev-deploy) in `ipv-core-common-infra`.
* **CI/CD Pipeline**: Automated deployments to shared development and build environments are managed via GitHub Actions post-merge pipelines.

For infrastructure definitions and environment configuration, refer to the [ipv-core-common-infra repository](https://github.com/govuk-one-login/ipv-core-common-infra).
